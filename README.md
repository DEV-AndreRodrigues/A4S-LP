# landing-pages · A4 Solutions

Uma pasta por landing page. Cada pasta vira uma URL.

| Pasta | URL (após publicar) |
|---|---|
| `notificacoes/` | `<dominio>/notificacoes/` |

## Criar uma nova landing page
1. Crie uma pasta com o nome da URL (minúsculas, sem espaços).
2. Coloque `index.html` e uma subpasta `assets/` com as imagens (caminhos relativos: `assets/arquivo.png`).
3. Faça commit na `main`. A publicação é automática (1 a 2 minutos).

## Atenção
- Repositório público: todo o código-fonte é visível, inclusive preços e textos.
- Não coloque nenhum dado interno, credencial ou LP não aprovada neste repositório.
